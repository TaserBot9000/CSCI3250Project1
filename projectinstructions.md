#Python Program: 
You are requested to write down a python script to scan your local
machine 127.0.0.1. The functionality of your program is like the nmap
functionality, but your script is not allowed to import the Python nmap
Library.

Your python script will be executed, from your local Machine, with the
command:
python3 myNmap.py 127.0.0.1

The script must output the TCP open ports on the target (screenshot 1).
The script must catch any error like no inputting the ip address of the
target (screenshot 2), inputting an ip address not reachable (screenshot 3)


# Advise on how to develop this project:
1. Code in your own laptop.
2. For testing use your own ip address: python myNmap.py 127.0.0.1
3. Debug your program in your own environment.
4. Run your program as specified previously and take the
corresponding screenshots.
Do a summary of the experience gained in this project, the problems
encountered, how did you solve the problems and answer the following
questions:
Questions:

1. How a client knows that a server has a tcp port open?

2. How a client knows that a server has a tcp port closed?

3. Did your script complete the three-way handshake? Why?

4. How a client knows that a server has a UDP port open?
